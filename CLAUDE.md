# CLAUDE.md — Project Entry Point

The authoritative public project instructions are in `AGENTS.md`. Read that file fully
before making changes.

When the following local files exist, read them in this order:

1. `.claude/OPERATING_INSTRUCTIONS.md`
2. `.claude/PROJECT_CONTEXT.md`
3. The latest entries in `.claude/PROJECT_TIMELINE.md`

Those files are intentionally ignored and contain local project context. Do not copy,
summarize, or expose their contents in tracked files, commits, public issues, pull requests,
or published pages.

For article writing or revision, also read `blog-post-instructions.md`.

After meaningful work:

- Update `AGENTS.md` only if public technical facts or operating rules changed.
- Append a dated entry to `.claude/PROJECT_TIMELINE.md` when it exists.
- Keep all project context inside this repository; do not update global/base memory.
- Never stage, commit, push, create a branch, or open a pull request unless explicitly asked.
